# Исходные МУПы

Положите сюда свои учебные планы `.xlsx`. Файлы не публикуются в Git.

Базовый `kini_config.json` ожидает:

- `МУП CS 26.xlsx`
- `МУП EEE 26.xlsx`
- `МУП Process Engineering 2026 (1) (2).xlsx`
- `муп логистика 26.xlsx`
- `муп мехатроника 26.xlsx`

Можно использовать другие названия: измените `groups[].file` в конфигурации.
