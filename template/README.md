# Шаблон расчёта

Добавьте сюда собственную книгу `расчет KINI 2026-27 (10).xlsx` или укажите
другой путь в поле `template` файла `kini_config.json`.

Рабочая книга не публикуется в Git. Генератор использует оформление и структуру
листа `Расчет`, своды `итог (основной)` / `итог (почас)` и связанные листы
направлений. Произвольный пустой Excel не заменяет этот шаблон.
